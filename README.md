# BR Christmas Particles v0.1.0 Beta

Transparent GPU Christmas particle source for Resolume Arena/Avenue on Windows.

Original effect by **Belajar Resolume**.

## Particle types

- Christmas Star
- Snowflake
- Christmas Ball
- Bell
- Candy Cane
- Gift Box
- Custom PNG/JPG/BMP
- Mixed

## Main features

- Continuous, Burst, and Continuous + Burst modes
- Start, Pause, Resume, natural Stop, Reset, and BURST
- Direction, gravity, turbulence, rotation, size, amount, speed, glow, and color
- Adjustable burst position and amount
- Custom image file picker
- Depth of Field and three quality levels
- Transparent output and MIDI/OSC-mappable parameters

## GitHub build

Upload all contents of this folder, including `.github`, to the root of a new GitHub repository. Open Actions, choose **Build BR Christmas Particles**, and run the workflow. Download `BR-Christmas-Particles-Windows-v0.1.0-beta`, extract its ZIP, then extract the nested `.tar.gz`.

## Install

Copy `BR Christmas Particles.dll` to `Documents\Resolume Arena\Extra Effects`, restart Resolume, then find the plugin under Sources.

For Custom PNG, select `Custom PNG`, click `Load Custom PNG`, and choose a transparent PNG. The path is saved as a Resolume parameter/preset value.
